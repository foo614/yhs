# FOO-182: Language-first buyer FAQ

## Scope and acceptance

Add one shared public-site widget. Opening it first offers Bahasa Melayu, English and 中文. A chosen language reveals six preset question/answer pairs, a language switch, back navigation, existing inventory navigation and the configured WhatsApp contact. Close/reopen retains the current screen only while the layout is mounted; a reload starts with language choice. No AI, free text, storage, API changes or personal-data collection.

## Implementation

- Centralize all copy in `apps/frontoffice/app/buyer-faq.ts`.
- Mount a client component from the root layout, outside the motion wrapper. Use a native modal dialog for focus containment, Escape and background isolation, with explicit focus restoration and scroll locking.
- Match existing burgundy colors and rounded controls. Keep the launcher and panel above the mobile navigation, with bounded scrolling on short screens.
- Reuse `business.ts` WhatsApp configuration and `hrefWithLanguage`. The site supports English/Chinese routes; Malay inventory navigation explicitly labels its English destination.

## Copy evidence

Existing `local-guides.tsx` supports budget filtering, financing enquiries with lender approval, and trade-in discussion with assessment. `business.ts` owns the existing sales contact. Warranty and test-drive availability are unconfirmed: answers ask sales to confirm these for the specific vehicle. Document examples are general, with the current checklist to be confirmed by sales. No financial rates, approval guarantees, warranty coverage or automatic bookings are asserted.
